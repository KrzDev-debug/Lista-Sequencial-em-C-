# Lista Sequencial em C++

Implementação de uma **lista sequencial estática** utilizando array em C++, com operações básicas de manipulação de dados via terminal.

---

## Funcionalidades

- Inserção de elementos
- Remoção de elementos
- Busca de elementos
- Acesso por índice
- Validação de entrada
- Interface via menu interativo

---

## Estrutura

- Lista sequencial estática (array)
- Controle de tamanho lógico da lista
- Manipulação por índices

---

## Complexidade

- Inserção: O(n)
- Remoção: O(n)
- Busca: O(n)
- Acesso por índice: O(1)

---

## Limitações

- Tamanho fixo definido em tempo de compilação
- Inserções e remoções exigem deslocamento de elementos
- Não há alocação dinâmica de memória

---

## Tecnologias

- C++

---

## Como compilar e executar

```bash
g++ main.cpp -o programa
./programa
